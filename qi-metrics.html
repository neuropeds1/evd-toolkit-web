  return items.length === 0
    ? html`<div class="fs-empty">Loading…</div>`
    : html`<ul>${items.map(i => `<li>${i.text}</li>`).join("")}</ul>`
}

Interactive VRI Benchmarking

Adjust the slider to compare an institutional ventriculostomy-related infection (VRI) rate against suggested quality benchmarks.

viewof vriRate = Inputs.range([0, 20], {label: "Institutional VRI Rate (%)", step: 0.1, value: 4})
// Port of QIMetricsScreen's zone lookup: low <1%, elevated <10%, high >=10%.
currentZoneKey = vriRate < 1 ? "low" : vriRate < 10 ? "elevated" : "high"
currentZone = qiBenchmarkZones.find(z => z.zoneKey === currentZoneKey)
currentZone
  ? html`<div style="padding:16px;border-radius:14px;background:${(currentZone.color ?? "orange")}22;border-left:5px solid ${currentZone.color ?? "orange"};">
      <strong>${currentZone.title ?? ""}</strong>
      <p style="margin:8px 0 0;">${currentZone.message ?? ""}</p>
    </div>`
  : html`<div class="fs-empty">Loading benchmark zones…</div>`

What is your unit’s VRI rate?

A quick self-check — use this to reinforce prevention practices, whatever your number is.

viewof myVRI = Inputs.range([0, 30], {label: "Your Unit's VRI Rate (%)", step: 0.5, value: 0})
myVRI === 0
  ? html`<div style="background:#e8f5e9;padding:15px;border-left:6px solid #27ae60;border-radius:10px;">
      <strong>🎉 Excellent — 0% VRI rate.</strong>
      <p style="margin:8px 0 0;">Keep reinforcing the fundamentals that got you here:</p>
      <ul style="margin:6px 0 0;">
        <li>Sterile technique and periprocedural antibiotics at insertion</li>
        <li>Indication-based CSF sampling only</li>
        <li>Minimizing unnecessary system access</li>
      </ul>
    </div>`
  : html`<div style="background:#fff7e6;padding:15px;border-left:6px solid #f39c12;border-radius:10px;">
      <strong>Your reported VRI rate is ${myVRI}%.</strong>
      <p style="margin:8px 0 0;">Every VRI is an opportunity to reinforce prevention. Revisit:</p>
      <ul style="margin:6px 0 0;">
        <li><strong>Insertion Bundle:</strong> sterile technique, periprocedural antibiotics, antimicrobial-impregnated catheter, tunneling, closed system, sterile dressing</li>
        <li><strong>Maintenance Bundle:</strong> indication-based sampling only, minimize system access, maintain system upright, prevent disconnection</li>
      </ul>
      <p style="margin:8px 0 0;font-size:13px;color:#666;">See the <a href="bundle.qmd">Infection Prevention Bundle</a> page for the full checklist.</p>
    </div>`
