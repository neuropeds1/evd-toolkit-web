Clinical Scenario

A neurocritical care patient with a clamped EVD is being transported for imaging.

Could transport increase the risk of ICP elevation?

This educational model explores factors associated with transport-related ICP elevation described in retrospective literature.

Factors Associated with ICP Elevation

  • Higher baseline ICP
  • Higher CSF output
  • Early ICU phase
  • Unplanned transport
  • Longer transport duration

Educational model inspired by retrospective literature on transport-associated ICP elevation with clamped EVDs.

Interactive Risk Assessment

viewof baselineICP = Inputs.radio(["<15", "15–19", "≥20"], {label: "Baseline ICP", value: "<15"})
viewof intubated = Inputs.toggle({label: "Patient Intubated", value: true})
viewof transportDuration = Inputs.range([0, 120], {label: "Transport Duration (minutes)", step: 1, value: 30})
viewof icuDay = Inputs.range([0, 30], {label: "ICU Day", step: 1, value: 5})
viewof csfOutput = Inputs.range([0, 30], {label: "CSF Output (mL/hr)", step: 1, value: 5})
viewof transportType = Inputs.radio(["Diagnostic", "Therapeutic"], {label: "Transport Type", value: "Diagnostic"})
viewof unplannedTransport = Inputs.toggle({label: "Unplanned / Emergent Transport", value: false})
// Port of TransportICPRiskScreen.kt's calculateRisk().
estimatedRisk = {
  let risk = 5;
  if (baselineICP === "15–19") risk += 20;
  if (baselineICP === "≥20") risk += 40;
  if (!intubated) risk += 10;
  risk += transportDuration * 0.25;
  if (icuDay <= 3) risk += 10;
  risk += csfOutput * 1.2;
  if (transportType === "Therapeutic") risk += 10;
  if (unplannedTransport) risk += 15;
  return Math.min(risk, 100);
}
riskCategory = estimatedRisk < 20 ? "LOW RISK" : estimatedRisk < 50 ? "MODERATE RISK" : "HIGH RISK"
riskColor = estimatedRisk < 20 ? "#27ae60" : estimatedRisk < 50 ? "#e67e22" : "#e74c3c"

Potential Mitigation Strategies

  • Conduct multidisciplinary huddle.
  • Reassess urgency of transport.
  • Optimize sedation before transport.
  • Review EVD clamp strategy.
  • Minimize transport duration.
  • Ensure ICP monitoring preparedness.
  • Clarify roles before transport.
  • Re-level immediately after transport.

Disclaimer

Warning

This educational model is hypothetical and intended for awareness, simulation-based learning, and educational purposes only. The transport-associated ICP risk model has not been prospectively validated and should not be used as a clinical decision-making tool. This tool is intended to promote awareness surrounding transport-associated ICP elevation and multidisciplinary transport preparedness. Clinical decisions should always rely on institutional protocols, multidisciplinary communication, bedside assessment, and clinician judgment.
